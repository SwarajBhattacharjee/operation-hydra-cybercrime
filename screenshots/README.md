# Screenshots

Place tool-output screenshots here before submission, e.g.:

- `mxtoolbox-spf-fail.png` — MXToolbox SPF/DKIM/DMARC check on a sample domain
- `virustotal-hash-scan.png` — VirusTotal scan result for a sample hash
- `abuseipdb-score.png` — AbuseIPDB reputation check on a sample IP
- `whois-domain-age.png` — WHOIS output showing recent registration date
- `log_parser-output.png` — Terminal output of `scripts/log_parser.py`

Name each file descriptively and reference it from the relevant
markdown file (e.g., `phishing-spoofing/analysis.md`) using
`![alt text](../screenshots/filename.png)` once added.
